# Student Management System

## Project Description
The Student Management System is a console-based Java application developed as part of the IncodeVision Java Programming Internship – Task 02.

It helps users manage student records using basic CRUD operations.

## Features
- Add student details
- View all student records
- Update student information
- Delete student records
- Prevent duplicate roll numbers
- Validate student marks
- Handle invalid inputs

## Student Information
- Student Name
- Roll Number
- Marks

## Technologies Used
- Java
- Object-Oriented Programming
- ArrayList
- Scanner
- VS Code

## How to Run

1. Install Java JDK.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Compile the program:

```bash
javac Student.java Main.java
```

5. Run the application:

```bash
java Main
```

## Learning Outcomes
- Understanding classes and objects
- Using constructors and methods
- Implementing ArrayList
- Performing CRUD operations
- Applying input validation
- Managing student records
